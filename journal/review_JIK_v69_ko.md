**JIK 투고 수정 전략 가이드 검토 결과와 v68·v69 반영 내역**

작성일: 2026-10-13 · 대상: 첨부 「JIK 투고용 논문 수정 전략 가이드」 · 최신 반영본: `manuscript_v69_ko_JIK.docx`(국문), `manuscript_v69_en_JIK.docx`·`title_page_v69_en_JIK.docx`·`highlights_v69_en_JIK.docx`(영문). 노란색은 JIK Revision 전체 변경(v68 + v69)이다.

## 1. 검증 결과

| 가이드의 주장 | 확인 결과 |
|---|---|
| JIK는 혁신과 지식의 연결이 중심이어야 하며, 포맷 변경만으로는 부족하다 | **맞음.** JIK 저자 가이드는 혁신 또는 지식과 관련 없는 원고를 대개 데스크 리젝트하며, 혁신에 대한 명시적 초점과 지식 영향과의 연결(또는 그 방법의 확장)을 요구한다(검색으로 확인; 이 환경에서는 Elsevier 사이트 원문 접속이 차단됨). |
| 원고의 언어를 technology convergence에서 knowledge integration으로 옮겨야 한다 | **부분 수용.** 원고 2.2절에 이미 지식 경계 논리(인터페이스가 불안정해지면 경계 너머 지식을 통합해야 하고, 공동분류는 그 흔적; Brusoni et al., 2001; Kapoor & Adner, 2012)가 있어 간극은 가이드의 진단보다 작다. 문제는 이 논리가 2.2절에만 있고 초록·서론·논의·결론에 드러나지 않았다는 점이다. JIK는 특허 기반 기술융합 논문도 싣고 있으므로(이미 인용한 Zhang & Zhang, 2025), 핵심 개념(공정 단계 간 기술융합)은 유지하고 지식 통합 해석을 전면에 덧붙였다(v68). 이어 교수님 요청에 따라 제목·RQ·절 제목과 3–5장까지 지식 통합을 축으로 정리하였다(v69, 4절). |
| 유지할 핵심 수치(45.8%, 37.2%, 31.3→62.2→44.3%, OR 11.071→2.452→0.658, 53.5→78.7→88.0%, Jaccard 값 9개) | **20개 모두 원고와 일치.** |
| 과잉 주장(지배적 설계 확립, 고착화가 원인, 다양성이 통합을 유발) | 원고는 대부분 이미 "부합한다" 수준으로 완화되어 있었다. 남아 있던 두 곳(국문 초록 "그 배경에 고착화가 있음", 영문 결론 "as the design … became entrenched")과 다양성 해석을 고쳤다. |
| 제출 전 필수 추가 분석(2023–2024 제외, 대체 시기 구분) | **분석은 하지 않음.** 이전 지시(v38에서 2023–2024 제외 재추정 삭제, v44 "추가 분석은 하지 말 것")를 따랐다. 대신 6.3절 한계에 공개 지연(18개월)과 시기 구분 문장을 추가했다(노란색, 원하지 않으면 삭제 가능). |
| 투고 실패 시 IEEE Access보다 TASM형으로 전환 | 동의. 새 알고리즘·공학적 기여가 없는 현재 형태는 IEEE Access보다 TASM에 맞다. |

## 2. v68에 반영한 것 (국문·영문 같은 위치, 노란색)

| 위치 | 반영 내용 |
|---|---|
| 초록 | 전·후공정을 "분리된 지식 영역"으로, 하이브리드 본딩이 요구하는 것을 "제조공정 지식"으로; 기술융합 = 공정 단계 간 지식 통합; CPC 공동분류 = 지식 통합의 흔적; 다양성은 "통합형이 더 다양한 기술을 포함"(구성상 연관); 마지막 문장을 "고착화와 부합하게 지식 통합은 사라지지 않고 위치를 옮긴다"로. 영문 초록은 250단어 유지(영문만 "기술 클러스터와 네트워크로 식별한" 구절을 덜어 냄). |
| 주제어 | "기술 네트워크" → **"지식 통합"**(6개 유지). |
| 서론 | 안정적 인터페이스와 구분된 지식 영역(Henderson & Clark, 1990; Brusoni et al., 2001), 인터페이스 불안정 시 지식 통합 요구(Grant, 1996), 연구 질문의 지식 관점 해석, 공동분류 = 발명 수준 지식 통합의 불완전하지만 관찰 가능한 흔적(Fleming, 2001), 세 기여에 지식 관점 문장 한 개씩. |
| 이론 | 2.1 지식 기반 관점(Grant, 1996; Fleming, 2001), 2.2 아키텍처 지식(Henderson & Clark, 1990 — 실증 대상이 반도체 노광 정렬 장비), 2.4 공동분류는 조직 간 지식 이전의 측정치가 아님. |
| 논의 6.1 | 지식 경계 논의를 수직 분리된 공정 영역으로 확장, 다양성은 인과가 아닌 구성상 연관, 지식 통합의 비선형 재편, 핵심 문장 "아키텍처의 성숙은 지식 통합을 없애지 않고 그 위치를 주변 구현 공정으로 옮긴다". |
| 6.2 | 생산 경계와 지식 경계는 일치하지 않으므로 인접 공정 지식 유지(Brusoni et al., 2001). |
| 6.3 | 공동분류는 지식 이전·흡수역량·혁신 성과의 측정치가 아님; 공개 지연과 시기 구분의 한계. |
| 결론 | 고착화 표현 완화, 지식 통합의 위치 이동, "혁신과 지식을 연결한다"는 종합 문장. |
| 참고문헌 | 3편 추가(서지 확인): Fleming (2001) *Management Science* 47(1); Grant (1996) *SMJ* 17(S2); Henderson & Clark (1990) *ASQ* 35(1). 55편 → 58편. |
| JIK 형식 | APA 7, 괄호 인용 "&"·알파벳순, JEL(L63; O32; O33; O34), 부록 표 A.1, 데이터 가용성·생성형 AI 선언, 하이라이트(영문 1·5번을 지식 통합 내용으로 교체), 줄번호. 국문판은 표지 → 하이라이트 → 원고를 한 파일에 담았다(형식 변경 자체인 APA 인용·참고문헌 서식은 노란색으로 표시하지 않음). |

## 3. 반영하지 않은 것과 이유

| 가이드 제안 | 판단 |
|---|---|
| 제목을 knowledge integration 중심으로 변경 | v68에서는 유지했으나, v69에서 교수님 요청(지식 강조)에 따라 "Cross-stage technology convergence **as knowledge integration** in semiconductor hybrid bonding: A patent-based longitudinal analysis"(국문: 공정 단계 간 기술융합**과 지식 통합**)로 변경. |
| RQ1–RQ3 문장 교체 | v69에서 반영: RQ1 두 영역 지식의 통합 정도와 형태, RQ2 공정 단계 간 지식 통합의 시간적 변화, RQ3 지식 통합이 일어나는 위치의 이동. 결과 절 제목·표 14·6.1 함의 제목·결론도 같이 맞춤. |
| 유형명 변경(Integrated → knowledge-integrating application) | 표·그림·부록 전체와의 일관성 때문에 유지하고, "관찰 가능한 흔적"이라는 해석만 더했다. |
| 2장 소제목 변경 | v69에서 반영: 2.2 "…과 지식 경계", 2.3 "…와 지식 통합의 위치", 2.4 "지식 통합의 관점에서 본 …". |
| 2023–2024 제외, 대체 시기 구분, 검색식 검증, earliest-filing 민감도 분석 | 이전 지시대로 분석은 추가하지 않았다(한계 문장만 추가). 동일 제목 중복 제거와 무관 용법 68건 제외 재추정은 이미 있다. 필요하시면 별도로 수행할 수 있다. |
| JIK 최근 문헌 추가 | JIK 논문 2편(Zhao et al., 2023; Zhang & Zhang, 2025)을 이미 인용하고 있다. 추가 인용은 서지를 확인할 수 있는 문헌을 찾은 뒤에 하는 것이 안전하다. |

## 4. v69 추가 반영 (교수님 요청: 원고 전체 문맥에서 knowledge 강조)

v68 확인 결과, 지식 표현은 초록·서론·이론·논의에만 있고 3–5장(본문의 약 58%)과 제목·RQ·절 제목에는 없었다. v69에서 다음을 국문·영문 같은 위치에 더했다(분석·수치·표 값은 그대로).

| 위치 | v69 반영 |
|---|---|
| 제목·주제어 | 제목에 "as knowledge integration"; 주제어 "지배적 설계" → "지식 경계"(지식 통합·지식 경계 두 개) |
| 초록 | 분석 대상을 "공정 단계 간 지식 통합의 수준과 유형, 시간적 변화, 통합이 일어나는 위치"로; 둘째 결과의 주어를 "지식 통합"으로(영문 250단어 유지) |
| 서론 | 연구 목적 문장에 "두 단계의 지식이 하나의 발명 안에서 통합되는 현상"; RQ1–RQ3 교체 |
| 2장 | 절 제목 3개, 2.1의 절 안내 문장, 2.3·2.4 끝의 굵은 요약 문장 |
| 3장 | 하이브리드 본딩 = 수직 분리된 단계의 지식 통합을 관찰하는 실증적 배경; 전공정 지식(평탄화·표면 화학·정렬)과 후공정 지식(다이 처리·적층·패키징)의 결합; 지식이 여러 조직에 분포 |
| 4장 | 두 클래스 = 서로 다른 지식 영역, 세 유형 = 한 영역 지식 / 두 영역 지식의 통합; 표 2 개념 열; 핵심 기술 = 핵심 지식 요소; Jaccard = 지식 통합 강도, 매개 중심성 = 통합이 일어나는 위치 |
| 5장 | 절 제목 3개; 5.1 "출원의 절반 가까이가 두 영역 지식을 통합"; 5.2 "지식 통합은 강화되었다가 다시 약해짐"; 5.3 "지식이 아키텍처의 어느 지점에서 통합되었는지", "통합 위치가 웨이퍼 제조공정에서 공정 장치·패키징 단계 공정으로"; 표 14 RQ 열 |
| 6.1·7장 | 세 함의의 굵은 제목을 지식 통합으로; 결론 첫 단락(융합 = 분리된 지식 영역의 통합)과 RQ별 결과 요약 |
| 하이라이트 | 영문 2·3번, 국문 2·3번을 지식 통합 표현으로 |

결과: 영문 "knowledge"는 25회(v66) → 59회(v68) → 113회(v69)로 늘었고, "knowledge integration"은 30회가 되었다. 지식이 들어간 절 제목은 6개이고, 모든 장(제목·초록·1–7장)에 지식 서술이 있다.

## 5. 투고 전 남은 일

- 노란색 선언문 확인: 감사의 글, 연구비, 이해상충, CRediT(교수님 역할), 데이터 가용성, 생성형 AI 사용 범위.
- 노란색을 지운 투고용 깨끗한 판 작성(요청 시 바로 생성).
- Cover letter(가이드의 세 문장 활용 가능), 그래픽 초록(선택).
- 교수님 최종 확인: 새 제목(as knowledge integration)과 새 RQ1–RQ3 문구.
