**학위논문 최종본(v84) → JIK 투고본(v86) 축약 내역**

## 6. v86에서 바뀐 것(v85 대비)

**2.5 분석 틀 삭제(유저 요청)**

- 2.5절과 표 1(이론–연구 질문–측정 대응표)을 국문·영문 모두에서 삭제하고, 본문 표 번호를 1–8로 당김(부록 표 A1–C2는 그대로).
- 2.5에 있던 단서 두 개는 옮겨 둠: 2.2 끝(특허 공동분류로 직접 관찰하는 것은 기술 융합 단계이며, 응용 융합은 지식 통합 위치의 변화로 간접적으로만 다루고 산업 융합은 분석 범위 밖), 2.3 끝(이론적 기대는 통계적 가설로 검정하지 않고 결과 해석의 기준으로 삼음).
- 번호를 당기면서 생긴 숫자 뒤 조사 오류 4곳 수정(표 1와 → 표 1과, 표 2은 → 표 2는, 표 3는 → 표 3은, 표 8는 → 표 8은), 같은 오류가 더 없는지 전수 확인.

**번역 점검: 내용이 달라질 수 있던 곳(국문·영문 함께 수정)**

- 초록·결론의 국면 설명: "통합형이 정점 → 감소"를 "통합형 **비중**이 정점 → 감소"로. 통합형 출원 **건수**는 56 → 130 → 239건으로 계속 늘었고 줄어든 것은 비중이라, 비중임을 분명히 함(5.2의 같은 표현도 수정).
- 6.2: 재편기에 핵심 기술과 결합한 제조공정이 다이 지지·패키지 공정이 "다수"라는 표현을 "가장 빈번한 것"으로. 두 기호는 206건 가운데 48건·43건이라 "다수"는 과장.
- 5.4: 핵심 기호 외 접합 기호 수를 통제한 결과 "승산비가 거의 변하지 않음" → "방향과 유의성이 유지됨(2014년 이전 11.071 → 8.768)". 실제로는 약 21% 줄었기 때문.
- 5.4: 군집 표준오차에서 유의성을 잃은 계수가 "하나뿐" → "다항 로짓에서 하나뿐". 핵심 기술 모형에서는 2015–2019년 승산비도 유의성을 잃기 때문(같은 절 뒷부분과 표 7에 이미 있음).
- 5.4 마지막 문장: "RQ1의 핵심 결과" → "RQ1의 핵심 회귀 결과(기술범위 → 통합형)". 통합형이 최다 유형이라는 기술통계는 정의에 따라 달라지므로.
- 5.2: 좁은 제조공정 정의·무관 용법 제외 표본의 통합형 연도 계수(0.967, 0.949)가 2010년 이후 표본 안의 결과처럼 읽히던 문장을 나누고 수치와 출처(표 C1)를 밝힘.
- 6.3: "이러한 절단" → "최근 출원의 절단"(바로 앞 문장이 시기 경계 이야기여서 무엇을 가리키는지 불분명했음).
- 2.3: "공정 장비" → "공정 장치"(분석에서 쓰는 제조공정 영역 이름과 일치).
- 2.3·5.1 국문: 비교 대상(다른 접합 발명보다), "약 10%", "기술범위의" 상대위험비를 넣어 영문과 같은 뜻으로.
