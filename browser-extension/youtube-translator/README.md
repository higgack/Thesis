# YouTube 번역 & 스크립트 + 두뇌저장 (크롬 확장)

유튜브 영상 자막을 원하는 언어로 번역해 **영상 위 오버레이**로 보여주고,
오른쪽에 **타임스탬프별 전체 스크립트(원문+번역)**를 정리합니다. 번역은
YouTube 자체 `timedtext` 엔드포인트(`tlang`)를 쓰므로 **별도 API 키·외부
번역 비용이 0원**입니다.

추가로, 스크립트 패널의 **🧠 RAG · 📒 노트** 버튼으로 현재 영상을
세컨드브레인(이 저장소의 봇)에 한 번에 학습시킵니다.

## 설치
1. `chrome://extensions` → 개발자 모드 ON
2. **압축해제된 확장 프로그램 로드** → 이 `youtube-translator` 폴더 선택
3. 자막 있는 유튜브 영상 열기 → 영상 위 번역 자막 + 오른쪽 스크립트 패널 확인

## 두뇌 저장 설정 (최초 1회)
확장 아이콘 클릭 → 팝업 하단 **🧠 두뇌 저장** 섹션:
- **대시보드 서버 주소**: 예 `http://34.50.23.221:8082`
- **DASHBOARD_TOKEN**: VM `.env` 의 `DASHBOARD_TOKEN` 값
- **저장 & 권한 허용** 클릭 → 해당 서버로의 호스트 권한을 허용하면 끝.

이후 영상 옆 스크립트 패널의 **🧠 RAG / 📒 노트** 버튼을 누르면 현재 영상
URL이 학습 큐에 들어가고, 텔레그램으로 `✅ 확장 학습 …` 알림이 옵니다.
같은 영상을 다시 눌러도 RAG·노트 둘 다 **중복 학습 안 함**(비용 0).

## 동작 원리 (요약)
- `inject.js` (MAIN 월드) → `getPlayerResponse()`로 자막 트랙 추출, `postMessage`로 전달.
- `content.js` → `baseUrl&fmt=json3` 원문 + `&tlang=<lang>` 번역을 `tStartMs`로 정렬, 오버레이·패널·재생 동기화.
- 저장 버튼 → `background.js`(서비스 워커)가 대시보드 `/<token>/ingest` 로 POST.
  HTTPS 유튜브 페이지에서 http 대시보드로의 직접 fetch는 mixed-content로
  막히므로, 권한을 가진 서비스 워커가 대신 요청합니다.

## 주의
- 영상에 자막(자동 생성 포함)이 없으면 번역/스크립트는 안 나오지만, 저장
  버튼은 동작합니다(서버가 yt-dlp→오디오 전사 폴백으로 처리).
- YouTube가 `timedtext` 접근 정책을 바꾸면 자막 추출이 일시적으로 깨질 수
  있습니다(외부 의존성). 저장 기능은 영향 없음.
- 네이티브 자막(CC)이 켜져 있으면 오버레이와 겹칠 수 있으니 끄는 걸 권장.
