# Manuscript

Put your paper here — drafts, sections, data, figures, references, and
generated artifacts (outlines, review reports, integrity audits).

Suggested layout (create as you go):

```
manuscript/
  outline.md
  draft.md            # or sections/01-intro.md, 02-methods.md, ...
  references.bib
  data/
  figures/
  artifacts/          # pipeline outputs: review reports, audits, passport
```

To begin, just tell Claude what you want — for example:

- "Guide me through framing my research question" → deep-research (Socratic)
- "Help me write a paper about <topic>" → academic-paper
- "Review this draft" (attach it) → academic-paper-reviewer
- "Produce a complete paper end-to-end" → academic-pipeline
