# 투자자용 운영 대시보드 KPI (우선순위 10)

이 문서는 텔레그램 기반 개인 RAG 시스템을 투자/운영 관점에서 관리하기 위한
핵심 지표를 정리한다. 목표는 "장애 없이, 예산 안에서, 의사결정 속도를 높이는"
운영 상태를 수치로 확인하는 것이다.

## 우선순위 기준
- P1: 서비스 지속성과 비용 통제에 직접 영향
- P2: 품질/회복력 개선에 영향
- P3: 고도화/확장 단계에서 영향

## KPI 목록

### 1) P1 - 인입 성공률
- 정의: 성공 인입 건수 / 전체 인입 시도 건수
- 이유: 지식 유입이 막히면 이후 위키/질의답변 가치가 모두 하락
- 권장 목표: 95% 이상

### 2) P1 - 질의 응답 성공률
- 정의: 정상 답변 완료 건수 / 전체 질의 건수
- 이유: 최종 사용자 체감 가치의 핵심
- 권장 목표: 98% 이상

### 3) P1 - 평균 응답 지연시간
- 정의: 질문 접수부터 답변 완료까지 평균 시간
- 이유: 생산성(의사결정 속도)을 직접 좌우
- 권장 목표: 일반 질의 10초 이내, 심화 질의 별도 트래킹

### 4) P1 - 일일 총비용 및 기능별 비용 비중
- 정의: 일일 총비용 + ingest/wiki/qna/notes 기능별 점유율
- 이유: 예산 초과 조기 감지, 고비용 기능 식별
- 권장 목표: 일예산 이내, 편중 기능에 상한선 설정

### 5) P1 - 배포 반영 지연시간
- 정의: 배포 브랜치 push 시점부터 배포 완료 알림까지 소요
- 이유: 장애 복구/개선 반영 속도의 핵심 지표
- 권장 목표: 자동배포 주기(1분) 기준 + 허용 오차 2~3분

### 6) P2 - 데이터 신선도
- 정의: 최근 24시간 신규 학습 문서 수, 마지막 학습 시각
- 이유: 의사결정 근거의 최신성 관리
- 권장 목표: 목표 수집량 대비 80% 이상

### 7) P2 - 실패 재시도 회복률
- 정의: 실패 큐 항목 중 재시도로 정상 복구된 비율
- 이유: 운영 회복력(Resilience) 측정
- 권장 목표: 70% 이상(소스 특성에 따라 조정)

### 8) P2 - 위키 누적 생산성
- 정의: 일일 위키 업데이트 토픽 수, 토픽당 비용
- 이유: 단발성 검색을 장기 지식자산으로 전환하는 속도 확인
- 권장 목표: 토픽 수 증가 + 토픽당 비용 안정화

### 9) P3 - 지식그래프 유효성
- 정의: 유효 관계(노이즈 제거 후) / 전체 추출 관계
- 이유: 분석 정확도와 설명 신뢰도 개선
- 권장 목표: 유효 비율의 지속 상승

### 10) P3 - 학습노트 활용도
- 정의: 생성 노트 대비 조회/재방문 비율
- 이유: "저장만 하는 시스템"인지 "실사용 시스템"인지 판별
- 권장 목표: 생성 노트의 50% 이상 재활용

## 운영 팁
- P1 지표는 대시보드 첫 화면 상단에 고정(색상 경고 포함)
- P2는 주간 리뷰, P3는 월간 리뷰로 관리
- KPI 임계치 초과 시 자동 알림을 두되, 변화 없으면 반복 알림은 보내지 않음
