# im-not-ai 검토 — 한글 문체 다듬기 (조건부, 학술 윤리 주의)

> 대상: [epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai) (MIT) — AI가 쓴 **한국어 텍스트를
> 자연스러운 한글**로 재작성하는 Claude Code 스킬. ~40개 AI 문체 패턴(번역투·기계적 "첫째·둘째"·수동태
> 남발·이모지) 감지 후 해당 구간만 수술적 수정. **사실·주장·수치·고유명사·직접인용 100% 보존.**
> Fast(단발) / Strict(7-에이전트) 모드.

## 우리 적합성
- 우리 논문은 한국어 → AI 초안의 번역투·기계적 나열을 다듬는 데 잠재적 유용. 수치·인용 보존은 우리 무결성과 합치.

## 주의 (왜 조건부)
- 제작자도 **"학술 제출 진위 검증용 부적합"**·"검출 우회 도구 아님"이라 명시. AI 작성물을 **사람 글처럼 위장**하는
  용도는 우리가 이미 넣은 **AI 사용 고지(Disclosure)** 및 학술 정직성과 충돌 소지.
- academic-paper 스킬에 **이미 Writing Quality Check / Anti-Pattern(IRON RULE)** 이 있어 AI 문체 교정 일부 중복.

## 결론
- **기본 미채택.** 쓰려면 **"검출 우회"가 아니라 한글 문체 품질 개선** 목적으로만, **AI 사용 고지를 유지한 채**
  선택 사용. 학위 심사 규정 확인 필수. 1차 교정은 academic-paper의 품질 체크로 충분한 경우가 많음.
