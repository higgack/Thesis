## 도구별 상세

### 1) kg-gen — 텍스트→지식그래프 (★★★ 적용 권장)
- **정체:** 평문 텍스트에서 엔티티·관계를 뽑아 지식그래프(KG) 생성. DSPy 구조화 출력, LiteLLM 멀티모델, MCP 서버 포함, 시각화. MIT, **NeurIPS'25 논문**(arXiv:2502.09956).
- **우리 적용 포인트:**
  - 우리 논문에는 **'기술 클러스터·기술 네트워크(CPC 동시분류)'** 절이 있다. kg-gen으로 **특허 초록/청구항·선행연구 텍스트에서 개념-관계 그래프**를 추출하면, 인용 기반이 아닌 **의미 기반 기술 네트워크**를 보조로 만들 수 있다(자료② 향후연구로 제시한 "텍스트마이닝 기반 특허 네트워크(Yoon & Park 2004)"와 정확히 부합).
  - 문헌 종합 단계에서 여러 논문을 KG로 합쳐 **개념 지도/갭 분석**에 활용.
- **차별점:** RAG-Anything은 검색(retrieval), kg-gen은 **구조 추출(KG)** → 경쟁이 아니라 **보완재**.
- **난이도/우선순위:** 중 / **상**. 경량·논문근거·MCP라 통합 부담 작음.

### 2) OpenKB — 문서→위키형 KB 컴파일 (★★★, 경량 대안)
- **정체:** 원문서(PDF/Word/MD/URL 등)를 LLM으로 **한 번 컴파일**해 요약·개념페이지·엔티티페이지·상호링크를 가진 **위키형 지식베이스**로 변환. **벡터DB 없이** PageIndex 트리 검색, markitdown, LiteLLM. Apache-2.0, 2.6k★.
- **우리 적용 포인트:**
  - 우리가 telegram-bot에서 겪은 **RAG-Anything의 무거운 설치(torch/CUDA, 디스크 부족)** 문제를 우회할 **경량 문헌 KB** 후보. 벡터DB·GPU 불필요.
  - "쿼리마다 재색인" 대신 **영속적 위키**로 쌓여 참고문헌을 반복 참조하는 논문 작업에 적합. 자동 개념/엔티티 페이지는 **문헌 리뷰 뼈대**로 유용.
- **차별점:** RAG-Anything(멀티모달·벡터)보다 **가볍고 영속적**이나, 표·수식 멀티모달 파싱은 RAG-Anything이 우위.
- **난이도/우선순위:** 중 / **상~중**. `rag/`의 경량 대안으로 시범 도입 가치.

### 3) kotaemon — 인용근거 문서 QA UI (★★☆)
- **정체:** PDF 채팅 RAG **UI**. **인용 하이라이트 + PDF 미리보기**, 멀티모달(표·그림), GraphRAG(LightRAG/nano/MS), 하이브리드 검색+리랭크. Apache-2.0, **25.5k★**(매우 성숙).
- **우리 적용 포인트:** 논문 작성 중 **주장-근거 검증**(어느 문헌 어느 페이지가 근거인지 하이라이트)에 강력. academic skills의 무결성 게이트와 결이 맞음.
- **차별점:** RAG-Anything은 스크립트/백엔드, kotaemon은 **사람이 보는 UI + 인용 시각화**. 보완적.
- **난이도/우선순위:** 중(앱 구동 필요) / **중**. "근거 확인 UI"가 필요할 때 도입.

### 4) AKB — MCP 에이전트 지식베이스 (★★☆, 라이선스 주의)
- **정체:** Git 백업 + **MCP**로 제공되는 에이전트용 지식베이스. 하이브리드 검색, URI 지식그래프, **Claude Code/Codex 플러그인**. 단 **BSL-1.1**(4년 후 Apache, 100시트 미만 무료), 61★(초기).
- **우리 적용 포인트:** **Claude Code에 MCP로 바로 연결**되는 에이전트 메모리 → 논문 자료를 세션 간 지속 기억. notebooklm-mcp와 유사한 통합 결.
- **차별점:** RAG-Anything 대비 **에이전트-네이티브·MCP**가 강점이나 라이선스·성숙도가 약점.
- **난이도/우선순위:** 중 / **중~하**. 통합은 매력적이나 BSL·초기성 때문에 관망.

### 5) ApeRAG — 엔터프라이즈 RAG 플랫폼 (★☆☆)
- **정체:** Graph+벡터+전문+vision 하이브리드, 엔티티 정규화 KG, MinerU 파싱, MCP 에이전트. Apache-2.0. **Postgres/Redis/Qdrant/ES/Neo4j + K8s**(권장 8GB+). 1.2k★.
- **우리 적용 포인트:** 기능은 최상위지만 **단일 석사논문엔 과도**. (우리가 겪은 디스크/자원 제약과 정반대 방향.) 다만 MinerU·MCP는 RAG-Anything과 같은 계열이라 **개념 참고**용.
- **난이도/우선순위:** 상(무거움) / **하**. 규모 커질 때 재검토.

### 6/7) lat.md — 코드베이스용 마크다운 지식그래프 (☆☆☆)
- **정체:** `[[위키링크]]` + 코드 백링크(`// @lat:`)로 **코드베이스 문서 지식그래프**. 에이전트가 코드 맥락을 빠르게 찾게 함. TS, MIT, 1.7k★. (discuss.pytorch.kr 글 = 이 프로젝트 소개; 본문 403이라 README로 확인.)
- **우리 적용 포인트:** **문헌·특허 분석엔 부적합**(코드 대상). 굳이 쓴다면 우리 레포의 **스킬/스크립트 문서 정리**용 정도. 논문 자체엔 적용점 없음.
- **난이도/우선순위:** - / **하**.
