# 대시보드 DESIGN.md — 디자인 토큰 & 규약

대시보드(읽기 전용 정적 HTML)의 **단일 디자인 소스**. 색·여백·타이포를
즉흥으로 찍지 말고 여기 정의된 토큰을 쓴다. 새 강조색이 필요하면 **먼저
`:root`에 토큰을 추가**하고 `var(--…)`로 참조한다.

> 정적 HTML은 `render` 모듈들이 생성하고 `server.py`가 서빙한다. 각 모듈은
> 자체 `:root` 블록을 갖는다(위키는 의도적으로 위키피디아풍이라 별도). 같은
> 토큰명은 모듈 간 의미를 일치시킨다.

---

## 1. 색 팔레트 (light / dark)

라이트/다크는 `[data-theme]`로 토글(시간대 자동). 공통 토큰:

| 토큰 | 의미 | light | dark |
|---|---|---|---|
| `--bg` | 페이지 배경 | `#f6f8fa` | `#0f172a` |
| `--panel` | 카드/패널 면 | `#ffffff` | `#1e293b` |
| `--panel-alt` | 보조 면 | `#fafbfc` | `#172033` |
| `--border` | 기본 테두리 | `#e5e7eb` | `#334155` |
| `--border-soft` | 옅은 구분선 | `#f0f2f5` | `#1e2738` |
| `--text` | 본문 글자 | `#1f2937` | `#f1f5f9` |
| `--muted` | 보조/메타 글자 | `#6b7280` | `#cbd5e1` |
| `--accent` | 링크/포커스 | `#3b82f6` | `#60a5fa` |
| `--primary` | 주 버튼(저장 등) | `#10b981` | `#10b981` |
| `--shadow` | 그림자 | 옅음 | 진함 |

(아카이브/노트/KG는 위 값이 거의 동일. `--bg`/`--border`는 모듈별 미세차 허용.)

### 시맨틱 강조 토큰 (4개 surface 공통)

| 토큰 | 용도 | light | dark |
|---|---|---|---|
| `--important` | ★ 중요 표시·"중요만" 필터 | `#f59e0b` (앰버) | `#fbbf24` |
| `--memo` | 📝 메모·"메모만" 필터·메모 미리보기 | `#10b981` (그린) | `#34d399` |

- 노트엔 `--due`(복습 임박, `--important`와 동값)도 있음 — 의미가 다르니 별도 유지.
- 메모 미리보기 박스의 옅은 배경/테두리는 `--memo` 계열의 알파 틴트
  `rgba(16,185,129,.08~.4)`를 쓴다(현재 리터럴; 알파는 hex 토큰으로 못 빼서 유지).

### 위키 전용 (위키피디아 테마)
`--link`/`--link-visited`/`--toc-*`/`--bq-*`/`--code-bg`/`--highlight` 등 별도.
`--accent`가 `#3366cc`로 다름. 위키 화면을 만질 때만 참조.

## 2. 타이포그래피
- 일반 surface: 시스템 산세리프 스택(기본).
- 위키 본문: `"Noto Serif KR", Georgia …` 세리프(문서 가독성).
- 메타/배지: 11~12px `--muted`. 제목: 굵게 `--text`.

## 3. 여백 / 모서리
- 카드 패딩 ~10–14px, 라운드 8–10px, 행 간격 6–10px.
- 필터/메모 버튼: padding `5px 12~14px`, radius 7px, font 12px/600.

## 4. 컴포넌트 색 규약
- **저장 버튼**: `--primary`(흰 글자). **삭제/해제 버튼**: `rgba(148,163,184,.25)` + `--muted`.
- **★ 토글·중요만 필터 활성**: `--important`.
- **📝 메모만 필터 활성·메모 미리보기 강조**: `--memo`.
- **알람 설정 버튼**: 인디고 `#6366f1`(위젯 전용, `widgets.py ALARM_CSS`).

## 5. Do / Don't
- ✅ 색은 토큰으로. 새 강조색은 `:root`(light+dark 둘 다)에 먼저 추가.
- ✅ 4개 surface에 같은 기능이면 같은 토큰·같은 클래스명(`memofilter`, `memo-preview`, `estar` 등).
- ⛔ 컴포넌트에 raw hex 직접 박기(특히 강조색). 기존 잔존 하드코딩은 점진적으로 토큰화.
- ⛔ 위키 토픽 페이지 CSS/HTML 변경 시 `_TPL_VERSION` 안 올리기(캐시가 옛 페이지 유지).

## 6. 마이그레이션 메모
지금은 `--important`/`--memo` 토큰을 **중앙 정의만** 해둔 상태. 기존에 박힌
`#f59e0b`/`#10b981` 솔리드 사용처(필터·★·메모 버튼)는 다음 손볼 때 `var(--important)`
/`var(--memo)`로 점진 교체. 알파 틴트 배경은 그대로 둔다.
